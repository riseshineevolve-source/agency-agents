## Architecture decision — baseline-first + deterministic deltas

For an edition that already has a trusted complete interior, the fastest reliable
production model is:

`APPROVED FULL-BOOK BASELINE -> PAGE HASH MANIFEST -> EXPLICIT FROZEN DELTAS ONLY -> ASSEMBLE -> VERIFY UNCHANGED PAGE PIXELS -> QA -> EXCEPTION-ONLY REVIEW`

This extends, not replaces, the canonical Book Map / dependency graph architecture.

For a new book with no trusted baseline, use normal source-first Book Map production.

### Why

The owner must not be asked to re-review 180 unchanged pages after a local correction.
An accepted page/book baseline is immutable until an explicit page delta is approved
and frozen. Unchanged pages are taken from the baseline, not re-rendered.

A structured page candidate cannot replace a baseline page merely because it exists
or passes technical QA. It needs the current source plus an explicit FROZEN page record.
