# SPRAWA 05 — SEJF PODPOWIEDZI + ROZWIĄZANIE

## POZIOM 1 // NA CO SPOJRZEĆ

Potraktuj **GWIAZDA → BŁYSKAWICA** jak jeden dwuelementowy blok. Potem sprawdź, które symbole muszą znaleźć się przed nim, a które po nim.

## POZIOM 2 // GDZIE SZUKAĆ

**PIŁKA** musi być przed GWIAZDĄ. **SERCE** jest po BŁYSKAWICY, ale nie może zajmować piątego miejsca. **KLUCZ** jest przed KSIĘŻYCEM, a SERCE również musi znaleźć się przed KSIĘŻYCEM.

## POZIOM 3 // MOCNIEJSZY TROP

Przesuwaj blok **GWIAZDA → BŁYSKAWICA** po kolejnych pozycjach. Tylko jedno ustawienie zostawia miejsce na PIŁKĘ przed blokiem oraz SERCE, KLUCZ i KSIĘŻYC w kolejności zgodnej ze wszystkimi wskazówkami.

## ROZWIĄZANIE

**PIŁKA → GWIAZDA → BŁYSKAWICA → SERCE → KLUCZ → KSIĘŻYC**

1. GWIAZDA stoi bezpośrednio przed BŁYSKAWICĄ.
2. PIŁKA musi znaleźć się przed GWIAZDĄ.
3. SERCE musi znaleźć się po BŁYSKAWICY i nie może być piąte.
4. KLUCZ musi znaleźć się przed KSIĘŻYCEM.
5. SERCE również musi znaleźć się przed KSIĘŻYCEM.
6. Wszystkie warunki jednocześnie spełnia tylko jedna sekwencja: **PIŁKA → GWIAZDA → BŁYSKAWICA → SERCE → KLUCZ → KSIĘŻYC**.

**DLACZEGO TO WAŻNE:** kod otwiera uśpioną skrytkę. W środku jest stara karta obiegu dokumentów z czarnym **0** i statusem **NIEUKOŃCZONE**. Sam kod trzeba zachować, bo wróci przy końcowej blokadzie.
