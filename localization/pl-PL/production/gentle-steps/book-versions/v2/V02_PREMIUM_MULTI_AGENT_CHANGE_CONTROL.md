# Gentle Steps PL Book V02 — Premium Multi-Agent Change Control

Status: **MANDATORY FOR ALL FURTHER V02 EDITS**

## Purpose

V02 must improve without collateral drift. A local improvement is rejected if it silently changes unrelated days, mechanics, safety language, back matter, character voice, or already-approved copy.

## Surgical edit protocol

For every meaningful slice:

1. **Freeze the base**
   - start from the latest canonical master;
   - create or identify a durable pre-edit snapshot;
   - do not edit frozen Book Version 1.

2. **Declare scope before editing**
   - list exact segment IDs allowed to change, e.g. `D14.MIĘDZY NAMI`;
   - no whole-book rewrite commands;
   - neighboring segments are read-only unless a logic defect proves they also require change.

3. **Make the smallest effective patch**
   - preserve already-strong wording;
   - preserve mechanics, counts, turn order, variants, safety and consent;
   - never regenerate an entire day to fix one line.

4. **Run independent specialist lenses**
   - **Polish Family Ear Reviewer:** real-family credibility, anti-cringe, no fake youth voice;
   - **Polish Natural Language Editor:** idiom, rhythm, translationese;
   - **Polish Book Register Editor:** premium written-book register;
   - **Polish Transcreator:** humor/emotional mechanism only where creative copy is being changed;
   - **Polish Logic Editor:** continuity, referents, repetition, neighboring logic;
   - **Activity Instruction Completeness Reviewer:** every game mechanic remains runnable;
   - **Polish Breath and Reset Editor:** concrete non-mindfulness reset language;
   - **Localization Meaning Guardian:** no semantic or instruction drift;
   - **Bilingual Localization QA:** final fidelity gate where source equivalence matters;
   - **Polish Proofreader:** grammar, punctuation and typography only after content is stable.

5. **Mechanical isolation gate**
   - `V02_SURGICAL_EDIT_GUARD.json` declares the base snapshot and exact allowlist;
   - CI compares all document segments;
   - any unallowlisted change fails;
   - preamble, day headers and post-Day24 back matter remain protected unless explicitly scoped.

6. **Regression + structure**
   - exactly 24 days;
   - exactly 24 × ZWOLNIJ / 24 × GRAMY / 24 × MIĘDZY NAMI;
   - 72 unique daily headings;
   - no reader-facing em dash;
   - frozen V1 Git blob remains unchanged.

7. **Checkpoint only after PASS**
   - save new master blob SHA;
   - save safe-state snapshot;
   - update manifest/QA/density evidence;
   - only then move the base forward.

## Premium editorial rule

Agents are reviewers with bounded authority, not independent whole-book rewriters.

A proposed improvement is accepted only when it is:
- materially better;
- native Polish;
- age-right for 8–12 without sounding childish;
- useful/funny/connecting in a real family;
- compatible with the 10-minute format;
- isolated to the declared scope;
- safer or equally safe;
- free of collateral regressions.

If a line is already excellent, **KEEP wins over rewrite**.

## Stop conditions

Content editing stops only when:
- full family-ear + logic + mechanics + proof pass finds no substantive defect;
- remaining gates are owner decisions, designed-template/physical proof, freeze or publication.
