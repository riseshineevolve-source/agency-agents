# V04 Editorial Board — Polish Market Final Pass

## Independent reviewers
1. Polish Family Ear Reviewer — would a Polish child/parent actually say/read this naturally?
2. Polish Natural Language Editor — syntax, collocations, idiom, word order, declension.
3. Polish Book Register Editor — good published-book Polish, not chat/UI/worksheet prose.
4. Narrative Designer — character voice, dialogue, scene rhythm, exposition.
5. Polish Transcreator — rebuilds jokes, punchlines and headings only where needed.
6. Audience / Age-Fit Reviewer (8–12) — clarity, anti-cringe, no baby language.
7. Puzzle Meaning Guardian — facts, clues, answers, coordinates, codes, non-spoiler wording.
8. Proofreader — last pass only.
9. Reality Checker — final question: "Could this have been written in Polish from day one?"

## Collaboration rule
Reviewers do not overwrite one another.
Independent reviews -> one Editor-in-Chief -> one controlled writer -> independent QA.

## Mandatory test
If an editor can hear the likely English sentence underneath a Polish sentence, the sentence reopens unless it is a locked code/rule/mechanical phrase.
