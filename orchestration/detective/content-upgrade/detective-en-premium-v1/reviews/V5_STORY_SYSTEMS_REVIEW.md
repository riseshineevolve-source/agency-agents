## FIX — book-wide

### S1 — Opening has too many onboarding functions competing
Pages 04–08 repeat orientation / team / method in different forms.
Keep the visual pages, but make each text surface perform one distinct job:
- P04: what kinds of investigation the reader will do;
- P05: stakes / connected story / Room Zero;
- P06: why a team works;
- P07–08: who each person is;
- P09: reader's decision to join.

### S2 — Reader's progression needs a visible relationship arc
The reader should not be called "Detective" as a generic greeting repeatedly.
Use recruit language early; let the team behave as if the reader belongs more and more after proven cases.

### S3 — Cases 02–05 need stronger cause/effect
The first four real cases should feel like the Academy is beginning to behave oddly, not like independent exercises.
Case 02 must clearly explain why Max's room companion can resolve the undocumented Cup return.
Case 03 should arise because the Case 02 witness points to conflicting images.
Case 04 can be parallel real-world work, but the old-system thread should remain in the background.
Case 05 should feel like an escalation: the system links a dormant locker to THIS session.

### S4 — Cases 10–15 are the main middle-book sag risk
Mechanics vary, but narrative entry is often "another problem arrives."
Add physical movement, consequences, interruptions and occasional emotional rhythm changes.

### S5 — Cases 16–21 should tighten toward the first direct message
This is the strongest pre-finale run. Make each beat feel increasingly connected:
photo -> RULE 0 FIRST -> Annex trip -> false 0:07 lead -> archive comparison -> saved map -> printer note.

### S6 — Cases 22–25 must feel like controlled frustration
The team has a message they cannot yet use.
Each ordinary case should quietly add one more map or lesson needed later, without announcing the answer.

### S7 — Cases 26–30 should be almost continuous
No reset tone. No "another case" feeling.
Treat as one five-part endgame.

## Desired emotional curve

Curiosity -> belonging -> pattern -> doubt -> old evidence wakes up -> direct message -> frustrating wait -> recontextualization -> revelation -> earned certification -> new mystery.
