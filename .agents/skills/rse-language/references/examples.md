# Short invocations

`Użyj $rse-language. Zrób polską wersję tej książki. Oryginał w załączniku.`

Infer source language/project, read locks/versions, choose localize, complete the
functional brief, assign a fresh native writer, backcheck, review and deliver a
complete candidate. Avoid generic style questions when the project defines voice.

`Użyj $rse-language. Dopracuj angielski tej wersji.`

Choose upgrade, inventory prior versions, protect GOLDEN_KEEP, diagnose the whole
book and patch bounded defects. Reuse its English variety unless specified otherwise.

`Użyj $rse-language. Gentle Steps: ulepsz dwa artykuły PL/EN.`

Protect the 24 days and product strings. Write sibling native campaigns. Mix a
pause, game and conversation teaser from three different source-verified days per
article. Use separate intents, concrete emotion and one truthful CTA. Do not create
a competing book translation.

`Użyj $rse-language. Przetłumacz najnowszy Detective EN na polski.`

Read the current R8 handoff first. Reuse verified Polish text where authorized;
do not create a competing draft. If this means migration to a later unfrozen EN
edition, inventory it and isolate the exact source freeze gate while continuing
safe diagnostics. Historical V10 authorization is scoped.

The Python CLI prepares/packets/checks/exports without an API key. The calling
assistant generates and reviews prose. It is not an unattended translation server
and does not run after a closed chat.
