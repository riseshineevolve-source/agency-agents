## Strong recommendation

Do not add new puzzle twists.

Use the existing mechanics as **story engines**:
- each answer changes the next action;
- each retained artifact can reappear physically;
- at least some cases should close with a visible consequence, not only a filed answer;
- the meta mystery should advance by recontextualization, not by arbitrary new clues.
