# ADR policy — RSE Universe Factory

Architecture after v1.0 may change only via a dated ADR.

Required fields:
- problem/evidence
- affected lanes
- current workaround
- proposed change
- alternatives considered
- cost
- throughput impact
- reliability impact
- security/privacy impact
- migration
- rollback
- owner approval requirement

A tool outage, one failed render, one bad prompt or one CLI configuration issue is NOT by itself an architecture reason.
