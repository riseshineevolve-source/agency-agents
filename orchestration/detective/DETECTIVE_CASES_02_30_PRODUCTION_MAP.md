## Purpose

This file converts the canonical V3/WOW case content into a repeatable production system.

It does **not** change story, clues, rules, answers, map geometry or case logic.

Case 01 is the master template:
- CASE INTRO = title + WHAT HAPPENED + OBJECTIVE + RULES + HAPPY MAKERS // COMMS;
- if that page becomes crowded, move COMMS to its own page instead of shrinking type;
- spatial cases use a facing spread:
  - LEFT / VERSO = full Witness Board;
  - RIGHT / RECTO = full Live Case Map + Verdict;
- non-spatial cases use one dedicated puzzle/evidence surface + Verdict;
- no generic duplicate “Evidence Grid” interlude pages;
- no artificial parity pages unless a real, designed interlude is intentionally required for spread parity.

## Global case-family rules

### A. CASE INTRO
Every case begins with:
1. CASE TITLE
2. CASE FILE / WHAT HAPPENED
3. YOUR OBJECTIVE
4. INVESTIGATION RULES
5. HAPPY MAKERS // COMMS

Requirements:
- premium modern graphic-novel dossier, never plain worksheet;
- large child-readable type;
- no filler slogans;
- HM COMMS uses exact locked portraits and readable numbered bubbles;
- witty/intelligent dialogue grounded in the actual case;
- if content does not fit comfortably, COMMS moves to a separate page.

### B. SPATIAL CASE
For the 15 spatial cases:
02, 04, 06, 07, 10, 12, 13, 15, 17, 19, 20, 22, 23, 25, 29

Use:
1. Case Intro
2. Witness Board — full left page
3. Live Case Map + Verdict — full right page

Witness Board:
- modern digital investigation-screen / dossier UI;
- only canonical witness facts;
- no corkboard/post-it visual language;
- no verdict fields;
- all witnesses required by the puzzle must be present;
- names/clues large enough for ages 8–12.

Live Case Map:
- owner Case 29 visual lock;
- white / clean cool-gray surface;
- exact rows/columns/walls/doors/room membership/blocked cells/usable cells;
- modern recognizable props;
- one clean label per room/zone;
- large bold axes;
- high-contrast MAP KEY;
- MAP KEY wall symbol must visually match wall rendering;
- verdict fields only on map page.

### C. NON-SPATIAL CASE
Use:
1. Case Intro
2. Puzzle / Evidence Surface + Verdict

Add a second evidence page only when the canonical puzzle physically requires a facing pair or multiple distinct source artifacts.

### D. PAGE REFS
Do not hardcode stale historical references such as page 8 / page 9.
Page references to:
- Standard Map Rules,
- Case Wall,
- Hint Vault
must be resolved from the final manifest after pagination is frozen.

## Act / pacing rule

Do not insert generic filler pages between cases.
Act dividers are allowed only where they are real story beats already present in V3/WOW.

A solved case may flow directly into the next case when the canonical transition supports it.

## HM Comms rule

HM Comms is story voice, not hidden evidence.

Do:
- humor;
- intelligent teasing;
- disagreement;
- case-grounded observations;
- character-specific thinking styles.

Do not:
- hide a rule in chat;
- repeat Objective/Rules verbatim;
- add answer clues not in canonical case truth;
- use generic AI filler.

## Freeze rule after Case 01 approval

Once the owner approves the Case 01 template:
- Intro template is locked;
- Comms visual grammar is locked;
- Witness Board visual grammar is locked;
- Map visual grammar is locked;
- Verdict visual grammar is locked.

Cases 02–30 may vary in puzzle content and required page count, but not in basic production quality or interaction hierarchy.
