# Owner Decision — Detective modern maps are a release requirement

Date: 2026-10-08
Status: AUTHORIZED / REQUIRED BEFORE FINAL KDP RELEASE CANDIDATE

The owner requires the final Detective Academy Book 1 English release to use the modern spatial-map system, not legacy/plain hybrid maps.

## Required final visual behavior

All 15 spatial cases must use the current verified source geometry and puzzle truth while presenting:
- modern premium grayscale props where approved/semantically safe;
- clean modern room/zone field;
- clear thick room walls;
- explicit correctly placed door gaps derived from locked runtime/source adjacency;
- bold readable coordinates;
- readable room/zone labels;
- a clear MAP KEY including at minimum blocked object, occupiable object, wall and doorway semantics;
- large usable map and verdict/write-in space;
- consistent puzzle and solution variants;
- premium detective-academy visual language, not worksheet/legacy-Shigai appearance.

## Logic lock

Modernization is presentation-only unless a proven source correction is separately authorized.

Do not change:
- grid rows/columns;
- room topology or source partition membership;
- blocked/occupiable semantics;
- clue-dependent object cells;
- witness/person placement;
- source clue meaning;
- verified answer identity/coordinate;
- Room Zero meta-carrier logic.

Walls and doors must come from locked source/runtime geometry. Do not guess or hand-draw new topology.

## Existing implementation evidence to reuse

There is an existing local codex/modern-props-pilot worktree/branch lineage containing:
- MAP_FACTORY_FINAL_SPEC.md;
- MODERN_PROP_PRESENTATION_CONTRACT.md;
- modern-prop inventories, replacement matrices and asset packs;
- render_spatial_map_runtime_illustrated_v4.py;
- all-15 hybrid/modern owner packet tooling;
- structure/footprint validators;
- final V4 map layout audit.

The illustrated renderer already encodes source-derived walls, source-derived doorway gaps, coordinates, room labels and MAP KEY semantics.

Do not start a new map architecture. Reuse and reconcile this existing work with current V12/Gold authority.

## Visual quality requirement

Earlier V4 pilot art was technically correct but some prop families were visually insufficient/generic. Do not blindly promote those weak sprites.

Before scale-out:
1. reconstruct the latest representative 6x6 / 7x7 / 9x9 map candidates from current locked source;
2. use current best modern prop assets and improve only unresolved/weak prop families;
3. require Visual Storyteller + Brand Guardian + print/finish QA;
4. preserve exact runtime geometry and all structure guards;
5. once representative maps are visually strong and technically green, scale mechanically to all 15 spatial cases;
6. run all-15 puzzle+solution geometry, door/wall, map-key, object/witness, clue/answer and print QA;
7. integrate those assets into the final 180-page V12 Book Factory release candidate.

No separate owner gate is needed for routine mechanical scale-out if the result follows this explicit requirement and the already-approved map grammar. Surface a gate only for a genuinely subjective new prop-art choice or a source contradiction.

## Release rule

A Detective KDP release candidate that still contains legacy/plain maps while the modern map lane is available is NOT final.

This map-modernization slice belongs inside the current Detective release sprint before final full-book KDP preflight.
