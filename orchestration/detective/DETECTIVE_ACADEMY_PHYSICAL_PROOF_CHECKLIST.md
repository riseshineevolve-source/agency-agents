## Acceptance rule

### PASS FOR EN FREEZE
Allowed only when:
- KDP Previewer/preflight has no unresolved blocking warning;
- physical proof has no BLOCKER;
- any BOUNDED FIX has been applied and rechecked;
- exact final interior source/artifact has been persisted remotely;
- exact final cover artifact is locked;
- owner explicitly states **FREEZE EN**.

### BOUNDED FIX
Use only for a concrete print defect, for example:
- unreadable repeated notes text;
- gutter collision;
- map label too small in print;
- grayscale element disappearing;
- answer space unusable;
- cover safe-area/barcode conflict.

Fix the smallest responsible component and rerun the affected deterministic/non-regression checks.

### BLOCKER
Examples:
- clue or answer becomes unreadable;
- map cannot be solved from print;
- Case 03 difference becomes ambiguous;
- text/art is clipped;
- wrong/missing/repeated page;
- reverse-entry system is physically confusing or broken;
- final cover no longer uses the canonical front.

## Freeze boundary

A successful proof does not freeze the book automatically.
