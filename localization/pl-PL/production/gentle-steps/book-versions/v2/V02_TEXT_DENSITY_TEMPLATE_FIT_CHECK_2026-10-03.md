## Fit interpretation

The six densest days are not automatically candidates for copy cuts. Most of their extra text protects one of four things:
- physical safety;
- consent / no-touch alternatives;
- group-size edge cases;
- instructions required for a game to work on the first read.

Blind shortening would create a higher risk than modest page density.

## Real-template proof checklist

When the actual designed-page template is available, verify each day at final print font size and trim:
1. no body text falls below the approved minimum readable size;
2. ZWOLNIJ / GRAMY / MIĘDZY NAMI remain visually distinct at a glance;
3. optional variants can be visually secondary without becoming unreadable;
4. safety and consent wording is never cut only to make a page fit;
5. Happy Makers comments remain attached to the activity they comment on;
6. no section is stranded on the next page with only a heading or one line;
7. the dense-day watchlist above receives individual page proof;
8. Day 1 still feels visually generous enough to function as the book's opening experience.

## Preferred fit order if a page overflows

1. tighten layout whitespace within the approved design system;
2. visually compress optional/challenge variants;
3. remove redundant connective wording;
4. only then consider copy reduction;
5. never remove safety, consent or the minimum rule set needed to play.
