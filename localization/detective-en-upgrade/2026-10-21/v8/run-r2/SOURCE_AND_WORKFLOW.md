# Source and workflow

Source is immutable. The skill performs diagnosis, KEEP/FIX selection, native writing and independent review.
Declare change-scope.json before editing; every changed segment must be allowed and have a reason.
For localization fill functional-brief.json then run packet. Give only the resulting packet to the first target-language writer.
Run check on the candidate. Machine PASS does not prove semantic fidelity, language quality, layout or release approval.
