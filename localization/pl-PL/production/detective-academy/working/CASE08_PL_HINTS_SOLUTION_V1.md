# SPRAWA 08 — SEJF PODPOWIEDZI + ROZWIĄZANIE

## POZIOM 1 // NA CO SPOJRZEĆ

Nie porównuj najpierw długości tras. Najpierw wykreśl każdą drogę, która łamie twardą zasadę.

## POZIOM 2 // GDZIE SZUKAĆ

Trasa A wchodzi w zamknięty **Korytarz Malarski**. Trasa B wymaga użycia zamkniętych **Schodów Personelu**.

## POZIOM 3 // MOCNIEJSZY TROP

Zostaje tylko trasa prowadząca przez **Magazyn Kostiumów** i **Boczny Korytarz**. Oba przejścia są otwarte.

## ROZWIĄZANIE

**TRASA C**

1. Trasa A odpada przez zamknięty Korytarz Malarski.
2. Trasa B odpada przez zamknięte Schody Personelu.
3. Trasa C prowadzi przez Magazyn Kostiumów i Boczny Korytarz.
4. To jedyna dozwolona droga do Magazynu Rekwizytów.

**DLACZEGO TO WAŻNE:** drużyna dociera do Magazynu Rekwizytów bez wchodzenia do zamkniętych stref. Sprawa z kostiumem może wreszcie ruszyć dalej.
