# Happy Makers Detective Academy — pl-PL Localization Profile

Status: **ACTIVE CALIBRATION / SECOND COMMERCIAL PRIORITY**
Locale: pl-PL
Source product: *Happy Makers Detective Academy: The Mystery of Room Zero*
Target: Polish KDP edition immediately after the English source is frozen

## Why this profile exists

Detective Academy is not a generic workbook. The Polish edition must preserve the feeling that the child has entered a real academy case file and is the missing member of the investigative squad.

The localization target is **native Polish adventure prose + exact puzzle logic**.

The Polish edition must not read like:
- translated educational material,
- a school worksheet,
- police/legal jargon for adults,
- literal English gaming copy,
- generic AI-generated children's prose.

It should read like a Polish book originally written as a smart, funny detective adventure for roughly ages 8–12.

## Immutable product signatures

Preserve these functions even when wording is transcreated:

1. the reader is recruited into the squad;
2. the physical book itself becomes evidence;
3. 30 missions form one book-long mystery;
4. solved cases can matter again later;
5. Rule Zero teaches evidence before assumptions;
6. the 3-level Hint Vault helps without shaming the child for being stuck;
7. solutions explain reasoning, not only answers;
8. Happy Makers remain a recognizable squad with distinct voices;
9. the `CHECK THE OLD MAP` meta mechanism must not be spoiled early;
10. maps, coordinates, answers, aliases, clue logic and Room Zero mechanics are logic-locked.

## Translation routing

### Logic-locked
Translate conservatively and validate bilingually:
- witness statements / clues,
- map instructions,
- solution reasoning,
- coordinates,
- answer/verdict sentences,
- ROOM / ZONE labels where meaning affects deduction,
- Hint Vault steps,
- callbacks that carry the Room Zero meta story.

Any semantic drift in these segments is BLOCK.

### Transcreation-friendly
Recreate function rather than syntax:
- hooks,
- Happy Makers banter,
- mission microcopy,
- dossier labels,
- marketing hooks,
- jokes,
- emotional encouragement,
- rank flavor text.

### Preserve as proper brand
Default:
- Rise.Shine.Evolve.
- Happy Makers

Do not translate the master brand.

## Signature copy candidates

These are transcreations, not literal translations.

> **30 SPRAW. JEDNA UKRYTA TAJEMNICA. W AKADEMII BRAKUJE TYLKO CIEBIE.**

## Ranks

Do not force awkward gendered child labels.

Avoid direct-address constructions such as:
- `Jesteś Rekrutem/Rekrutką`
- `Młody Detektyw / Młoda Detektywka`

Prefer rank badges as impersonal level names.

Initial candidates:
- TRAINING → **SZKOLENIE**
- ROOKIE → **POZIOM: START**
- FIELD AGENT → **POZIOM: TEREN**
- MASTER DETECTIVE → **POZIOM: MISTRZOWSKI**
- ROOM ZERO → **POKÓJ ZERO**

These rank translations remain **provisional until layout + full-story review**.

## Character voice

Happy Makers dialogue must remain differentiated.

General rule:
- do not make everyone equally witty,
- do not add jokes to factual clues,
- jokes may move culturally but not change clue meaning,
- Grandma Bibi / Babcia Bibi should sound warm, sharp and experienced, not old-fashioned for comic effect,
- child/young squad voices should be lively without TikTok imitation.

Where a character line carries both humor and logic, logic wins.

## Names and aliases

Public adventure aliases such as Nova, Echo, Blaze, Clover, Scout, Pixel, Dash, Sage, Juno, Atlas, Rook and Skye normally remain unchanged in Polish unless a specific name creates a pronunciation/readability problem.

Do not Polish-spell branded aliases.

Inflect names naturally only when Polish grammar clearly requires it and the result is unambiguous.

## Logic preservation rules

For every spatial case:
- preserve exact person identity mapping,
- preserve coordinates,
- preserve row/column relations,
- preserve room membership,
- preserve adjacency / diagonal / order / exclusion logic,
- preserve number of people,
- preserve answer identity,
- preserve solution chain,
- preserve ROOM versus ZONE semantics.

A more elegant Polish sentence is a failure if it changes the deduction set.

## Clue localization pattern

Preferred process:
1. write the literal semantic proposition in plain Polish;
2. verify the proposition against source logic;
3. rewrite into natural child-facing Polish without changing logical operators;
4. check negation, exclusivity, direction, ordinal number, row/column and adjacency;
5. run bilingual logic QA.

Examples:

Source:
`NOVA was in row 2 and column B.`

Good:
`Nova była w drugim rzędzie, w kolumnie B.`

Source:
`CLOVER was in a corner and beside a refrigerator.`

Good:
`Clover była w rogu mapy i tuż obok lodówki.`

Never strengthen `beside` into `in the same room as`, or weaken an exact coordinate into an approximate location.

## Hint Vault

The Hint Vault should feel safe, not punitive.

Use:
> **SEJF PODPOWIEDZI**

Recommended progression:
- POZIOM 1 — **Na co spojrzeć**
- POZIOM 2 — **Gdzie szukać**
- POZIOM 3 — **Mocniejszy trop**

Avoid:
- `łatwa odpowiedź`,
- `ściąga`,
- language implying the child failed.

## Solutions

Solutions must preserve the reasoning-first advantage.

Target style:
- concise,
- concrete,
- sequential,
- no unexplained answer dump.

Prefer:
> `Najpierw ustaw Novę w B2. To zajmuje drugi rząd i kolumnę B. Teraz...`

Avoid stiff schoolbook prose such as:
> `Na podstawie powyższych przesłanek należy stwierdzić...`

## Surface budgets

Polish commonly expands relative to English. For compact surfaces:
- prioritize function over word-for-word loyalty,
- keep badge labels short,
- preserve large readable type,
- reflow cards instead of shrinking text excessively,
- never omit a clue to make it fit.

The Polish edition may use a slightly different line break/page-flow pattern while preserving the same content and paired-page logic.

## Polish KDP edition sequence

Do not translate from an intermediate English build.

Start full-book localization only when:
1. English canonical 30-mission master is frozen;
2. ALL-15 spatial logic is PASS;
3. final aliases are frozen;
4. Witness Board / map page families are stable;
5. English source segment IDs are available.

Then:
1. extract localizable segments;
2. classify logic-sensitive vs transcreation-friendly;
3. seed Detective glossary;
4. translate in bounded batches;
5. run semantic + logic gates;
6. run native Polish edit;
7. render Polish surfaces;
8. fix layout pressure;
9. bilingual QA;
10. Polish KDP preflight.

Because maps and geometry are reusable, do not recreate art that contains no English text.
