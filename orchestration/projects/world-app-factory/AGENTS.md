# World App Factory lane rules

Read `PROJECT_BRIEF.md`, both World execution bootstraps, the RSE autonomy
protocol and the World lane mailbox before continuing. Read live branch status
and the newest lane checkpoint rather than restarting an old mission slice.

One writer owns the shared runtime and both content-pack families. Helpers may
work on explicitly disjoint files; do not run concurrent writers on the same
script, branch/worktree or source surface. Inspect status/diff before Git
operations and preserve legitimate uncommitted work.

Source order is authoritative. Never change copy, speakers, IDs or provenance
to satisfy a stale derived count. Reconcile unambiguous count errors from the
published page; surface only unresolved canonical-source contradictions.
Never resurrect the resolved World 01 code-summary gate.

Use deterministic validation first. Keep source binaries/artwork private unless
an exact asset export is separately authorized. Do not commit personal absolute
paths or temporary screenshot paths into source manifests. Preserve duplicate
published pages and intentional source variants with distinct provenance.

Run targeted source or runtime checks after relevant changes, record limitations
and exact hashes/heads, checkpoint, and refresh only this lane's mailbox.
Do not change Central, Gentle Steps or Polish Localization surfaces.
