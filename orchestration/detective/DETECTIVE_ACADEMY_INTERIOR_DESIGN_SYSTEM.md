## Purpose

This file preserves the final owner-approved design and non-regression rules for the Detective Academy interior so a new worker/chat can resume without reconstructing decisions from conversation history.

The target is not merely a valid puzzle book. The interior must feel like a **modern premium Detective Academy system**: logical, repeatable, beautiful, readable, black-and-white print-safe, exciting for ages 8–12, and clearly part of the Rise.Shine.Evolve. / Happy Makers product universe.

**No backward steps.** If a prior approved iteration had stronger structure, clearer section hierarchy, better HM Chat treatment, or better reader usability, restore or improve it rather than simplifying it away.

---

## 1. Recurring case structure — non-negotiable

Every case must follow a recognisable repeated system, using the applicable sections in this order:

1. **CASE NUMBER / CASE TITLE / STATUS**
2. **MISSION BRIEF / narrative setup**
3. **YOUR OBJECTIVE**
4. **HAPPY MAKERS CHAT / FIELD NOTE**
5. **INVESTIGATION RULES / MAP RULES / HOW TO SOLVE** where required
6. **EVIDENCE / WITNESS STATEMENTS / MAP / CHART / PUZZLE**
7. **YOUR VERDICT / ANSWER ENTRY**
8. Optional **CASE WALL UPDATE / ROOM ZERO SIGNAL** only where canonically required

Required principle:
**Objective -> Happy Makers guidance -> solving rules/evidence -> answer entry.**

A recurring section may never disappear into ordinary body copy merely to save space.

Do not silently remove:
- YOUR OBJECTIVE;
- HAPPY MAKERS CHAT;
- required rules/instructions;
- answer / verdict fields;
- name / coordinate fields where the puzzle requires them.

No content may be lost during layout repair.

---

## 2. HAPPY MAKERS CHAT — component lock

Happy Makers Chat is a signature narrative layer, not filler copy.

It must:
- render as a visually distinct recurring component;
- separate speakers clearly;
- preserve one speaker/beat per line or clearly separated mini-card;
- have visible spacing above and below;
- be immediately recognisable on every case page;
- remain compact enough for print but never become a squeezed inline paragraph.

Reject:
- multiple speakers collapsed into one ordinary paragraph;
- chat jammed between labels and witness statements;
- inconsistent styling from case to case;
- reducing chat to generic body text.

Target feel:
**modern Academy comms / field-note exchange**, not comic-book speech bubbles and not a school worksheet.

---

## 3. YOUR OBJECTIVE — component lock

YOUR OBJECTIVE must be one of the fastest elements to find on every case.

Use a consistent modern framed component:
- strong label;
- one clear action;
- generous internal spacing;
- no decorative clutter;
- identical visual hierarchy across cases.

The child should be able to open any case and answer within seconds:
**What am I trying to solve?**

---

## 4. Rules / guidance

Use a dedicated rules/guidance component only when the puzzle genuinely needs it.

Examples:
- MAP RULES / WITNESS KEY;
- INVESTIGATION RULES;
- HOW TO USE THE EVIDENCE;
- puzzle-specific constraints.

Rules must never be hidden inside narrative prose.

Do not repeat unnecessary generic rules on every page if the mechanic is already established; preserve clarity without wasting space.

---

## 5. Answer / verdict area

Every case must provide a deliberate writable response surface matching the exact puzzle.

Examples:
- person / witness name;
- coordinate;
- code;
- sequence;
- selected item;
- written verdict.

Spatial cases should clearly separate:
**YOUR VERDICT // WITNESS / PERSON**
and
**COORDINATE**

Other puzzle types must use equivalent exact answer fields.

Never remove the writable answer area in order to make the page look cleaner.

---

## 6. Witness Board / Evidence presentation

Witness Board must feel like a **modern investigation interface translated into premium black-and-white print**.

It must NOT look like:
- a plain spreadsheet;
- a generic table;
- a school worksheet;
- a stack of undifferentiated rows.

Preferred treatment:
- modular clue / witness cards;
- clearly numbered evidence units;
- strong witness-name hierarchy;
- compact metadata labels;
- modern evidence rails / cards / grouped fact blocks;
- clear checkboxes only where useful;
- strong alignment and generous breathing room;
- visual grouping that helps solving.

The presentation may vary slightly by case family, but the underlying system must remain recognisable.

---

## 7. Signature Detective pattern — EVIDENCE GRID

Canonical recurring black-and-white motif:
**EVIDENCE GRID**

This is not an ordinary school grid.

It is a modern hybrid of:
- coordinate micro-grid;
- evidence-board structure;
- subtle investigation nodes;
- restrained connection lines;
- blueprint/map logic;
- scanner / detection overlay.

Visual requirements:
- monochrome;
- very high print clarity;
- sophisticated;
- sparse;
- never decorative clutter;
- never Christmas/ornamental;
- never Victorian/retro detective styling.

Use selectively on:
- section headers;
- objective cards;
- HM Chat panels;
- answer surfaces;
- divider pages;
- signal / archive / evidence modules;
- subtle edge or corner accents.

Do not place the full pattern behind dense body text.

Interior usage:

- symbol only, no full wordmark;

## 9. Modern-world design language

The Academy is contemporary / near-future, not old detective nostalgia.

Use:
- scanner language;
- modern evidence boards;
- clean rails/cards;
- coordinates;
- structured files;
- digital/forensic visual cues adapted to B&W print;
- modern typography and spacing.

Avoid:
- antique detective desks;
- aged paper as the dominant language;
- Victorian files;
- cork-board cliché overload;
- decorative globes as identity;
- banker-lamp / Sherlock aesthetic;
- ornamental seasonal foliage;
- faux vintage type.

---

## 10. Typography / hierarchy

The reader-facing hierarchy must be consistent from page to page.

Audit every page for:
- heading scale;
- section-label consistency;
- body readability;
- speaker differentiation;
- line spacing;
- card padding;
- orphan/widow problems where materially ugly;
- printable whitespace;
- unclipped labels;
- no text collisions.

Do not shrink text simply to preserve a decorative layout.
Fix composition first.

For ages 8–12, readability takes priority over fitting one more decoration.

## 18. Definition of visual DONE

A final candidate is visually ready only when:
- every case uses the recurring structure consistently;
- no required section is missing;
- HM Chat renders consistently everywhere;
- Objective is immediately visible;
- rules are clear where required;
- answer space matches the puzzle;
- Witness Board/evidence presentation feels modern and premium;
- Evidence Grid pattern is applied coherently;
- scanner-question-mark symbol is used consistently and sparingly;
- stale names are eliminated or explicitly justified;
- all 146 pages pass human page-by-page review;
- no logic/art/answer regression occurs;
- physical proof confirms comfortable print readability.

Only after this + physical proof + explicit owner decision may English be frozen.
