# Detective Academy — Map Visual Lock
Date: 2026-09-30
Status: OWNER DIRECTION / ACTIVE

## Owner visual anchor

The owner supplied a Case 29 map mockup on 2026-09-30 and confirmed this is the target visual direction for map pages.

Use that visual language across all spatial case maps while preserving exact locked puzzle geometry, coordinates, room topology, blocked/usable status, witness logic and answers.

## Required visual system

- full-page map presence; map should dominate the page;
- strong black graphic-novel frame/header;
- clear case title: `CASE XX // LIVE CASE MAP`;
- large bold coordinate axes with generous spacing;
- thick walls and obvious door gaps;
- soft light-gray floor surfaces only where useful for depth;
- modern, recognizable grayscale props with enough visual detail to identify the object immediately;
- props centered within their intended cell/footprint;
- room/zone names as high-contrast black badges or equivalent single clean label;
- no split/double label boxes for one room name;
- no label sitting on top of wall lines;
- no title collision with column labels;
- black high-contrast MAP KEY band;
- large bottom verdict area:
  `PERSON / WITNESS` + `COORDINATE`;
- usable/blocked markers remain unambiguous;
- no tiny technical microtext.

## Content/logic invariants

Do NOT change:
- grid dimensions;
- cell identity;
- walls/doors;
- blocked vs usable state;
- room/zone membership;
- clue-relevant prop identity;
- coordinate labels;
- puzzle answer;
- witness placement truth.

Modern prop upgrades are presentation-only.

## Print-readability rule

At actual 8.5x11 print size:
- axis letters/numbers must read instantly;
- room badges must be legible without zooming;
- prop silhouettes must remain identifiable in grayscale;
- key and response area must be comfortably readable for ages 8–12.

## Production note

The old simplified line-icon maps are no longer the visual target.
The owner-supplied Case 29 mockup is the style target: premium modern detective floor-plan / graphic-novel dossier, not worksheet diagram.
