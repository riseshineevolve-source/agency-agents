## 1. Gold-master principle

The final book must read as one connected mystery adventure, not as 30 worksheets.

Each case has two jobs:
1. solve a small believable local mystery;
2. move, preserve or test one part of the larger Room Zero investigation.

The Room Zero system never causes the ordinary incidents. It routes/reopens existing Academy records. The reader solves the real case first; only afterward may the file contribute to the larger pattern.

## 2. Critical contact-case clarification

In spatial/contact cases, the named anchor person is **not missing** and is not automatically a victim or suspect.

Example:
"Max was the trophy keeper" means Max is the known anchor in the record. The child reconstructs the recorded positions to discover who shared Max's room at the relevant time. That person becomes the next useful person for the team to question.

A shared room proves only:
- same recorded area/time;
- possible contact/access;
- a useful next interview.

It does NOT prove:
- theft;
- guilt;
- a handover;
- disappearance.

### Reader-facing micro-rule

Introduce this once in Case 02 and use only a small reminder afterward:

**CONTACT CASE RULE**  
The named person is our anchor. Find who shared their recorded room. That gives us the next person to ask — not someone to blame.

## 3. Final recurring case structure

Use this order wherever applicable:

1. **CASE / TITLE / STATUS**
2. **CASE FILE // WHAT HAPPENED** — short story paragraph, normally 3 sentences:
   - setting / how this file reaches the team;
   - what actually happened;
   - why the next deduction is useful now.
3. **YOUR OBJECTIVE** — one imperative, no story repetition.
4. **INVESTIGATION RULES / HOW TO SOLVE** — only the rules genuinely needed for this mechanic.
5. **HAPPY MAKERS CHAT** — 3–5 short lines; character/relationship/humor; never critical hidden evidence.
6. **EVIDENCE / WITNESS BOARD / MAP / VISUAL PUZZLE**
7. **YOUR VERDICT / RESPONSE SURFACE** — mechanic-specific, never a generic one-line answer box.
8. **CASE CLOSED** — one-sentence local result.
9. **KEEP THIS / SIGNAL LOG** — only what the reader genuinely needs later.

The child should always know:
**What happened? -> What am I trying to find? -> What rules apply? -> What do the Happy Makers notice? -> What evidence do I use? -> How do I record the answer? -> What do I keep?**

## 4. Response-surface contract

Never use the same answer line for every puzzle.

- Spatial/contact case: **PERSON / WITNESS** + **COORDINATE**.
- Case 03 exact-ten differences: child marks/circles all 10 directly on the images; use only a completion control such as **ALL 10 FOUND [ ]**, not one answer line.
- Code puzzle: four ordered code slots.
- Route puzzle: choose/circle Route A/B/C; optional one short reason field if useful.
- Mark comparison: mark the matching samples directly; record only the final classification if needed.
- Timestamp classification: circle/select A–D.
- Timeline: four ordered slots.
- Reconstruction: piece-order slots + a full-width line to copy the reconstructed instruction.
- Direction/visual sequence: FROM / TO or arrow-choice surface.
- Case 26: fourteen letter boxes in case order.
- Plan overlay: mark the location on the image + one short LOCATION field.
- Fact/theory sort: writable/drop zones for FACT / THEORY / UNSUPPORTED + the recovered rule word.
- Finale: four distinct fields for the four earned answers.

## 5. Main-plot escalation

### Act I — SOMETHING IS OFF // Cases 01–06

### Act V — THE DOOR OPENS // Case 30
Earlier answers close the Room Zero mystery. Dated routing evidence explains why these files reached the reader. Detective Six is certified. Only then does a separate Book 2 file arrive.

## 7. Case-close contract

Every case should close locally before the meta beat.

### CASE CLOSED
One plain-English sentence explaining the immediate local conclusion.

Examples:
- "Dax is the next witness to question about the trophy's return route."
- "Route C is the only route the team can use without crossing a blocked or staff-only path."
- "The photographs contain ten verified changes."

### KEEP THIS
Only if the reader needs the item/record later:
- completed map;
- code sequence;
- photo record;
- ticket sleeve;
- torn-note instruction;
- etc.

### SIGNAL LOG
Use only a genuinely earned meta observation. It may be:
- a matching mark;
- an archive memory;
- a false lead;
- an empty field;
- a method update;
- a next action.

Do not force a giant new 0 onto every case.
