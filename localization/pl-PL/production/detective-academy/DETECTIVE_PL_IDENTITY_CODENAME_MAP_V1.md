## Non-negotiable rules

1. One English display identity has exactly one Polish codename across the entire book.
2. The same mapping is used in narrative, Witness Board, map labels, hints, solutions, answer keys and callbacks.
3. Never rename a witness locally inside a case.
4. Repeated English display aliases across cases use the same Polish codename.
5. No Polish codename is assigned to two different English display identities.
6. On each Witness Board, the visible roster must mix name rhythms/endings; do not create a board composed only of `-a` names or only of `-o` names.
7. Do not use near-duplicate codenames that are easy to confuse in puzzle solving. Example: `KODRA` is locked; `KODRO` is rejected.
8. Character/case IDs, portraits, coordinates and solution truth remain the mechanical authority.
9. If a later source audit discovers additional English identities, assign a new unused Polish codename and add it here before using it in production.
