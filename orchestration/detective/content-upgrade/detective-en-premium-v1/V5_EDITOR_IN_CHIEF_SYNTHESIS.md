All reviewers agree on the same core diagnosis:

The mechanics and fair-play twist architecture are strong.
The remaining gap is not "more clever puzzles."
It is **continuous detective-story causality**.

V5 therefore does NOT rewrite the book indiscriminately.

## Allowed changed surfaces

- opening narrative/informational copy Pages 04–12;
- act transition prose;
- `CASE FILE // WHAT HAPPENED` narrative prose Cases 01–30;
- Room Zero thread/checkpoint narrative prose;
- Happy Makers Chat only when a documented voice/repetition issue exists;
- Room Zero explanation narrative/dialogue;
- Archive File 001 prose only if required for continuity (current default KEEP).

## Protected surfaces

- publication/legal page;
- titles unless factual contradiction requires owner gate;
- objectives;
- Investigation Rules except opening workflow description;
- evidence/puzzle content;
- witness statements;
- maps;
- verdict fields;
- hints;
- solutions;
- all locked answers/twists.

## One-writer rule

Only the local Middle-Grade Mystery Writer may author V5 prose.
Reviewer docs are read-only evidence.
Editor-in-Chief accepts/rejects changes after diff + regression.

## Writer quality test

For every changed case intro:
- Why now?
- What changed?
- Why care?
- Why this deduction?
- What does solving it unlock?

If the new version cannot answer all five without repeating the Objective, it is not premium yet.

## Stop condition

Stop creative rewriting when:
- logic/continuity PASS;
- story-flow PASS;
- age/agency PASS;
- character voice PASS;
- humor PASS;
- puzzle regression PASS;
- full-book reader pass finds no substantive narrative defect.

Do not iterate just because alternate wording exists.
