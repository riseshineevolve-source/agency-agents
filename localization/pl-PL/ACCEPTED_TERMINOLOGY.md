## Provisional, not globally locked

`DILO: FAKT Z BŁĘDEM W SYSTEMIE`

Reason: Round 2 preserves it as the current candidate for `Dilo's Glitchy Fact`, but recurring source occurrences must be reviewed before it becomes a character-level glossary lock. Do not invent alternate Dilo labels ad hoc. Until verification, preserve the current candidate consistently within calibration work and flag it for glossary review.

## Regression rules

1. Do not replace a locked label merely for stylistic variety.
2. If a locked label creates a real fit/meaning problem on a new surface, flag the conflict rather than silently shortening it.
3. Any approved glossary change must migrate all affected recurring occurrences together.
4. Character-specific terminology remains separate from core product terminology and requires source recurrence validation.
5. Accepted terminology does not override semantic fidelity. If the English source uses a different function, translate that function rather than forcing a glossary term.
