# V03 Editorial Board — SMART EFFICIENT

One controlled writer only. Reviewers are read-only and non-overlapping.

## Editor-in-Chief / RSE Orchestrator
Owns segment allowlists, source truth, decision priority and integration.

## 1. Source Function Analyst — Research Synthesist
For each segment extracts wording-free:
- narrative function;
- required facts;
- puzzle mechanics;
- clue/answer dependencies;
- emotional job;
- humor job;
- speaker;
- callbacks.

Does not propose polished Polish.

## 2. Native Polish Book Co-Author — PRIMARY WRITER
Writes from the functional brief, not English syntax.
Owns Polish prose, dialogue, headings and transitions.
Only writer allowed to mutate the V03 master.

## 3. Internationalization Engineer / Polish Usage Editor
Read-only review:
- calques;
- word order;
- collocations;
- idiom;
- declension;
- punctuation;
- false friends;
- unnatural register.

## 4. Narrative Designer
Read-only review:
- character voice separation;
- dialogue that real people would say;
- exposition disguised as dialogue;
- setup/payoff;
- pacing and scene energy;
- Room Zero thread continuity.

## 5. Cultural Localizer / Polish Family Ear
Read-only review:
- Polish family/school speech;
- age 8–12 naturalness;
- humor timing;
- cultural distance;
- anti-cringe.
May suggest local adaptation only when it does not alter locked visual/puzzle truth.

## 6. Game Designer / Puzzle Validator
Read-only review:
- objective clarity;
- instructions;
- counts;
- order;
- coordinate and code integrity;
- unique solution;
- Hint Vault escalation;
- no wording that leaks answers.

## 7. Psychologist / Child Audience Reviewer
Read-only bounded review only where relevant:
- age-fit;
- pressure/shame;
- forced disclosure;
- emotional safety;
- reader agency.
Does not turn the book into therapy language.

## 8. Proofreader
Last linguistic pass only after content stabilizes.
No creative rewriting.

## 9. Reality Checker
Final independent gate:
- does it actually read like a Polish book?
- can the English syntax still be heard underneath?
- did cultural adaptation accidentally change puzzle truth?
- are there any fake PASS claims?

## Collaboration law
**MANY INDEPENDENT REVIEWERS -> ONE EDITOR-IN-CHIEF -> ONE CONTROLLED WRITER -> INDEPENDENT VALIDATION**

No sequential full-book rewrites by multiple writers.
