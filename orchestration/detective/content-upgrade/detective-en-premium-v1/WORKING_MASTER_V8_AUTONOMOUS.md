# PAGE 11 // MAP CASES — READ THIS ONCE

# MAP CASES

## READ THIS ONCE

Some cases use an Academy floor grid to reconstruct where people were standing.

Read these rules once. Later map cases will only give you the case-specific key.

## 1 // HOW TO READ A COORDINATE

Letters run across the columns.  
Numbers run down the rows.

**D3 = column D, row 3.**

Use one coordinate system: the labels printed beside the grid you are solving.

## 2 // STANDARD MAP CASE RULES

1. Place every witness exactly once.
2. Each witness finishes in a different row and a different column.
3. Use only printed witness statements and visible map features.
4. If a case asks for a room or area companion, that person is a lead for the next interview, not automatically guilty.
5. Keep every final witness position on the completed map. Do not erase it after writing the verdict.

## 3 // MAP LEGEND

**USABLE FLOOR = ○**  
A small **open circle** in the corner of a square means a person may stand there.

**BLOCKED OBJECT = ●**  
A small **solid circle** in the corner means that square is occupied by a fixed object and cannot hold a person.

**WALL = THICK BLACK LINE**

**DOORWAY = A CLEAR GAP IN A WALL**  
A doorway is shown by the wall stopping and continuing after the opening. It is not a separate filled box.

**ROOM / ZONE:** named areas on the map. If a rule specifically says **ROOM**, a ZONE does not count.

**Do not use the background shade of a square to decide whether it is usable. Read the corner marker and the walls.**

## CASE 05 // DILO'S CODE THAT DEFINITELY WASN'T 123456


**ANSWER:** BALL -> STAR -> BOLT -> HEART -> KEY -> MOON


1. STAR must sit immediately before BOLT.
2. BALL must be somewhere before STAR.
3. HEART must come after BOLT and cannot be fifth.
4. KEY must come before MOON.
5. HEART must also come before MOON.
6. Testing the possible positions leaves one sequence: **BALL -> STAR -> BOLT -> HEART -> KEY -> MOON**.


**WHY IT MATTERS:** The code opens the dormant locker and reveals an old routing card stamped **0** and marked **INCOMPLETE**. The code itself is saved for the final lock.

# PRODUCTION APPENDIX E // NARRATIVE-BRIDGE AUDIT — NOT READER-FACING

Every case introduction must answer four questions in natural story prose:

1. **Where did this file come from now?** — live request, routed record, archive find or direct continuation.
2. **What happened locally?** — the concrete small mystery.
3. **Why this deduction?** — what the team will gain by solving this specific puzzle.
4. **How does it sit inside the larger Room Zero story?** — through transition, preserved evidence or deliberate pause from the meta mystery.

Audit result after the 2026-09-28 story-flow + WOW pass: **30/30 case intros meet the four-part narrative requirement and every Case -> next Case transition is causally bridged, deliberately parallel, or explicitly time-shifted.**

## E1 // SOURCE-MIX LOCK

Across the thirty cases, vary how the next mystery reaches the squad. Use a deliberate mix of:
- intake printer / dormant Academy system;
- Academy staff or mentors asking for help;
- a problem the Happy Makers witness themselves;
- an event inside a specialist Academy wing;
- a nearby partner venue or field exercise;
- a direct continuation of the previous case.

Do not make every case arrive from the printer. Do not make every case occur inside the same building. Every transition must explain why the squad encounters that case **now**.


Contact-case purpose is explicit: a same-room or same-area contact becomes the next useful witness and a later transition shows what that follow-up unlocked; proximity never proves guilt.

Non-contact cases state the local stakes in the story, while the exact task appears once in YOUR OBJECTIVE rather than being repeated in the intro and chat.

The main plot advances through follow-ups, preserved records, Case Wall retrievals and earned callbacks. A solved case should either close its local problem, produce the next lead, or add evidence that later returns, so the child experiences one detective novel built from thirty playable cases rather than thirty worksheets.
